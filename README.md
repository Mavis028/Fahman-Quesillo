# Fahman Quesillo

Animated one-page website for **Fahman Quesillo**, a Venezuelan quesillo stand in Korba, Heliopolis, Cairo.

- 📍 الكوربة – مصر الجديدة، عند أبو عمار السوري في وش حرية مول
- 🗓️ Every Thursday & Friday, from 3 PM until sold out
- Instagram: [@fahman_quesillo](https://www.instagram.com/fahman_quesillo/)

## What's inside

`index.html` (Arabic, RTL) plus optimized WebP photos in `images/`:

- Animated hero: floating quesillo photo with sparkles
- Photo step cards and a full-width street-cart photo that zooms on scroll
- Scrolling ribbon with days, hours and location
- "What is quesillo?" cards with small animations
- Interactive slicing game
- Live open/closed badge based on Cairo time
- Map and Instagram links
- Responsive layout; animations respect `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser. No build step needed.

## Deploy

Works on any static host. For GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
